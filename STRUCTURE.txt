LAYER RESPONSIBILITIES
═══════════════════════════════════════════════════════

Domain Layer (CricketBazar.Domain)
└─ Pure business logic
   ├─ Entities: Product, Category
   ├─ Interfaces: IProductRepository, IBaseRepository
   └─ No external dependencies

Application Layer (CricketBazar.Application)
└─ Business rules & orchestration
   ├─ DTOs: ProductDto, CreateProductDto
   ├─ MediatR Commands & Queries
   ├─ Handlers: Process business logic
   ├─ Validators: FluentValidation rules
   └─ Mappings: AutoMapper profiles

Infrastructure Layer (CricketBazar.Infrastructure)
└─ Data persistence & external services
   ├─ DbContext: Entity Framework Core
   ├─ Repositories: ProductRepository, BaseRepository
   ├─ Migrations: Database schema versions
   └─ External integrations

API Layer (CricketBazar.API)
└─ HTTP communication
   ├─ Controllers: ProductsController
   ├─ Middleware: Error handling, logging
   ├─ Routes: RESTful endpoints
   └─ Configuration: Startup, DI, CORS

Shared Layer (CricketBazar.Shared)
└─ Cross-cutting concerns
   ├─ Constants: ApiConstants
   └─ Exceptions: BusinessException

GETTING STARTED
═══════════════════════════════════════════════════════

1. Backend Setup:
   $ cd Backend
   $ dotnet restore
   $ dotnet build
   $ dotnet run --project src/CricketBazar.API

2. Frontend Setup:
   $ cd Frontend
   $ npm install
   $ ng serve

3. Database Setup:
   $ docker-compose up -d

4. API Documentation:
   → http://localhost:7000/swagger
